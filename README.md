# TaskApp releases

This repository holds nothing but the installable builds of TaskApp, a personal to-do app,
and one small file that tells the Android app which version is current.

- `android/version.json` is what the Android app reads to learn that a newer version exists.
- The builds themselves are attached to the releases: the Windows installer with its
  `latest.yml` feed, and the Android `.apk`.

There is no source code and no personal data here. The apps are windows onto a private page
that only their owner's account can open, so a copy of a build shows a sign-in screen and
nothing else.
